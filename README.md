
# CoCo Assembler Hangman - text version

First CoCo 6809 assembler program written in a long while for me.


## PSEUDO CODE for the game

- show title screen
- spin on variable to get "random" value
- pick word from list with random value
- clear screen
- show empty HANGMAN
- show missing letters
- ask for a guess
- if guess right, show letters
- if guess wrong, add part to HANGMAN
- if too many guess, hangman died
- if correct word guessed, play happy music, and start over
- else go back to "ask for a guess"
